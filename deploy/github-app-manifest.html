Create the keel-bridge GitHub App

An owner of the GitHub organization Keel-Linux opens this file in a browser that is signed in to GitHub, and pushes the button. GitHub shows the App settings. Push "Create GitHub App". GitHub then goes to git.pop.coop/Keel-Linux/keel-bridge with ?code=... in the address. Give that code to the operator of the bridge. The code is valid for one hour.

The App can write issues and pull requests, and read metadata. It cannot write code, workflows or settings. It has no webhook.
